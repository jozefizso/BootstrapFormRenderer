BootstrapRenderer is an extension for Nette web applications for rendering
forms using Bootstrap styling.

BootstrapRenderer targets Nette framework 3.0 and 3.1, Latte 2.6+ and the Bootstrap CSS v2.x.
Library must work on PHP 7.1, 7.2, 7.3, 7.4, 8.0, 8.1, 8.2 and 8.3 runtimes.

Use Context7 to access documenatation about Nette 3.0/3.1, Latte 2.x and Bootstrap v2.
Ensure the documentation is for the versions used in this project.
